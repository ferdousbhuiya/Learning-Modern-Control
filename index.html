Purpose: stabilize an unstable cart-pole system after a disturbance. Choose a controller, apply an impulse, and observe how feedback drives cart position and pendulum angle back toward equilibrium. What are we learning?

  1. Unstable dynamics: the upright pendulum naturally falls without feedback.
  2. State feedback: the controller uses x, ẋ, θ, and θ̇ to compute force u.
  3. Gain design: LQR chooses gains from a cost tradeoff; pole placement chooses gains to achieve desired closed-loop poles.
  4. Disturbance rejection: an impulse tests whether the controller can recover.
  5. Performance: compare settling, angle recovery, cart travel, and control effort.

Goal of the lab

By the end, you should be able to explain state → feedback gain K → control force → closed-loop response, and describe why different gain designs can stabilize the same plant with different performance.

What are we learning?

  1. Coordinate control: specify where the robot hand should go using X and Y.
  2. Inverse kinematics: convert the target position into joint angles for the two links.
  3. Reachability: discover that a robot cannot reach points outside its physical workspace.
  4. Tracking: watch the actual end effector converge toward the requested target.
  5. Error: use tracking error as a measurable indicator of controller performance.

Goal of the lab

By the end, you should be able to explain the chain desired position → inverse kinematics → joint configuration → controlled motion → measured position → tracking error, and relate it to real robotic manipulators.

THEORY & MATH DOCS

State-Space & Modern Control Reference

State-Space Form

ẋ=Ax+Bu
y=Cx+Du

A captures internal dynamics, B input influence, C output mapping, and D direct feedthrough.

Controllability

𝒞=[B AB … Aⁿ⁻¹B]

Full rank means the input can influence every state direction.

Observability

𝒪=[C; CA; …; CAⁿ⁻¹]

Full rank means internal states can be reconstructed from outputs over time.

Lyapunov Equation

AᵀP+PA=-Q

For Hurwitz A and Q>0, the positive definite solution P gives a quadratic stability certificate.

LQR Cost

J=∫(xᵀQx+uᵀRu)dt

Q weights state error; R weights control effort.

Discrete-Time Stability

x[k+1]=A_dx[k]+B_du[k]

Stable discrete poles lie strictly inside the unit circle.
